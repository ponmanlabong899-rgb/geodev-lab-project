# My GeoDev Lab Africa project

Where are Jos's tin-mining ponds concentrated, and how has the
extent of mined/degraded land in Jos North and Jos South LGAs
changed between 2000 and 2024?

Built over twelve months with GeoDev Lab Africa, Cohort One.
See **project-brief.md** for the full brief.
## Month 2
- Week 5: Ran my first Python script (hello.py) from the terminal.
- Week 6: set up the project with uv and added pandas. check.py prints the pandas version.
- Week 7: analyse.py reads wards.csv, converts each area and classifies each ward.
- Week 8: inspect_data.py reads water_lines_km.csv, my Month 1 water lines, and reports the length of each stream.
- Week 9: summary.py refactors Week 8 into three functions plus summarise_all, and summarises the same data.
